# Pre-Deployment Checklist

Before deploying, ensure you have:

## ✅ Code Ready
- [ ] All code committed to git
- [ ] Build runs successfully locally (`npm run build`)
- [ ] Server starts in production mode (`npm run start`)
- [ ] Test on `http://localhost:5001`

## ✅ Environment Variables Configured
Add these to your deployment platform:

### Required
- [ ] `NODE_ENV=production`
- [ ] `JWT_SECRET` (minimum 32 characters, use: `openssl rand -hex 32`)
- [ ] `DATABASE_URL` (PostgreSQL connection string)

### Optional (for full features)
- [ ] `OPENAI_API_KEY` (for AI thumbnail generation)
- [ ] `STRIPE_SECRET_KEY` (for payments)
- [ ] `STRIPE_WEBHOOK_SECRET` (for payment webhooks)

## ✅ Database Setup
- [ ] PostgreSQL database created
- [ ] DATABASE_URL environment variable set
- [ ] Run migrations: `npm run db:push`

## ✅ Deployment Platform Settings

### Railway
- [ ] Build Command: `npm run build`
- [ ] Start Command: `npm run start`
- [ ] Root Directory: `/`

### Render
- [ ] Build Command: `npm install && npm run build`
- [ ] Start Command: `npm run start`
- [ ] Environment: `Node`

### Replit
- [ ] Run Command: `npm run build && npm run start`
- [ ] All secrets added via Secrets panel

## ✅ Post-Deployment Tests
- [ ] Homepage loads with proper styling
- [ ] Can create account
- [ ] Can login
- [ ] AI features work (if API key configured)
- [ ] No console errors (F12)

## 🔧 Quick Commands

Generate JWT Secret:
```bash
openssl rand -hex 32
```

Test build locally:
```bash
npm run build
npm run start
# Open http://localhost:5001
```

Check what's deployed:
```bash
curl https://your-app-url.com/
curl https://your-app-url.com/api/health
```
